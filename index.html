#基于IPM的多传感器融合BEV模型

输入
车周围一圈摄像头图像，多个激光雷达
输出
车周围一定范围的目标物体位置和大小
方案
多个摄像头图像经过图像的backbone之后，不同scale的feature通过ipm投影到BEV空间，多个激光雷达的点云通过特征提取和voxelization把激光雷达的特征也变换到BEV空间，激光雷达的特征经过激光雷达的backbone，然后和图像的BEV特征进行concat，最终接输出预测的head预测3d box

改进点细节

  1. 数据增强，图像色彩，bev空间flip，旋转，drop sensor等
  2. 多层ipm，增加height预测，多层ipm按照高度分布预测加权
  3. 多帧时序，多帧bev feature对齐拼接

#基于LSS的多传感器融合BEV模型

输入
车周围一圈摄像头图像，多个激光雷达
输出
车周围一定范围的目标物体位置和大小
方案
多个摄像头图像经过图像的backbone之后，预测特征和深度分布，深度分布对于每个像素而言是一条camera发出的射线，所有像素的摄像构成一个视锥，把特征和深度分布点乘把特征放至视锥对应位置，然后按照空间网格voxelization成bev特征， 多个激光雷达的点云通过特征提取和voxelization把激光雷达的特征也变换到BEV空间，激光雷达的特征经过激光雷达的backbone，然后和图像的BEV特征进行concat，最终接输出预测的head预测3d box

改进点细节

  1. 数据增强，图像色彩，bev空间flip，旋转，drop sensor等
  2. 增加深度分布的真值作为监督
  3. 多帧时序，多帧bev feature对齐拼接

#单目3D目标检测

输入
摄像头图像
输出
摄像头出现障碍物的2d/3d box，和属性
方案
摄像头图像经过第一个stage的backbone后接yolo 2d detection, 第二个stage用第一stage的2d box 从backbone feature crop出roi feature作为第二stage的输入，第二stage接head 预测3d box（depth/heading），和遮挡截断等属性

改进点细节

  1. 数据增强，图像色彩，flip，crop，resize等
  2. 预测观察视角代替heading

#自制基于VLA的机械臂

整个机器人小车模仿开源机器人LeKiwi，但是这个全买下来要四五千，我制作的版本成本几百元

机械
模仿SO-101，自己画3D图纸，用3d打印制作缩小版so-101，关节构造类似，尺寸不一样
硬件
机械臂6个用飞特scs0009舵机，主控是esp32，接ov2640 camera，电机驱动，电机
底层软件
esp32通过wifi和局域网中的电脑连接，esp32实时发送图像到电脑，电脑端键盘可以控制机械臂移动，可以控制小车移动
VLA算法
电脑同步记录机械臂的控制信号，小车移动信号和摄像头图像，作为训练数据，训练SmolVLA，最终可以实现小车自动捡垃圾到垃圾桶
